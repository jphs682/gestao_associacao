# Documentação

Esta pasta concentra a documentação detalhada do projeto, separada por assunto.

- `arquitetura/` — Documento de Arquitetura de Software (DAS) e decisões arquiteturais.

- `levantamento/` — informações obtidas junto à associação.
- `requisitos/` — requisitos funcionais, não funcionais e regras de negócio.
- `modelagem/` — modelo de dados, diagramas e escopo funcional.
- `desenvolvimento/` — estrutura do projeto, Git e roadmap.

Documento principal de arquitetura: [DAS — Sistema de Gestão de Associações](arquitetura/DAS.md).
- `testes/` — testes previstos.
- `projeto/` — documentação acadêmica, metodologia, avaliação, impactos e resultados.
- `manual/` — manual de utilização, a ser produzido durante o projeto.
