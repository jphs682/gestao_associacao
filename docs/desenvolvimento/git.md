# Controle de versão

O projeto utiliza **Git** para controle de versão e **GitHub** para hospedagem do código-fonte.

Sugestão de fluxo de desenvolvimento:

```text
main
 │
 ├── develop
 │    │
 │    ├── feature/associados
 │    ├── feature/contribuicoes
 │    ├── feature/historico
 │    └── feature/interface
 │
 └── releases
```
